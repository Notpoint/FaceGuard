# FaceGuard · 护屏

FaceGuard 是一个 macOS 菜单栏应用。在本机分析摄像头画面，检测到两张或更多人脸时发出提示音，帮你留意其他人入镜。它只检测人脸和位置，不识别身份。

- 使用 Apple Vision，结合全图与重叠分区检测小脸；合并重复框，对与已有脸重叠的可疑框作复核。
- 在实时预览中标注人脸框和面积；用第二大人脸的面积在可调的最小、最大警报音量之间变化。面积只调节声音，两张脸才触发警报。
- 可以选择在警报期间将指定应用拉到前台。该选项默认关闭；警报结束时停留在目标应用。菜单栏可随时暂停检测并解除置前。
- 支持调整窗口大小、滚动设置页和隐藏到菜单栏。系统成功注册快捷键时，Option＋空格切换预览，Control＋Option＋P 暂停检测。

## 从源码构建

需要 macOS 13 或更新版本，以及包含 Swift 编译器和 macOS SDK 的 Xcode 或 Command Line Tools。无需第三方依赖或模型下载。已在 Apple Silicon 上验证构建；Intel 构建未实测。

```sh
./scripts/build.sh --test
./scripts/build.sh
open build/FaceGuard.app
```

脚本在当前架构构建并对本地应用做临时签名。首次使用点击「开始检测」并授权摄像头。关闭预览窗口后仍会在菜单栏运行；使用「暂停检测」释放摄像头。最小音量建议先试听到可以清楚听见，实际响度也取决于系统音量和输出设备。

## 隐私和限制

应用在本机处理摄像头画面，不录制、不上传，不收集人脸身份信息。设置保存在本机。仓库不包含摄像头样本或测试照片；`Resources/beep.wav` 是项目生成的短提示音。

极小、模糊、明显侧转、背对或被遮挡的脸可能漏检，同一张脸也可能偶发被重复计数。采集分辨率取决于摄像头和可用模式，应用优先请求 1080p。指定应用置前是桌面提醒，不是系统锁屏，不能固定目标应用内部的标签页或文档。

源码位于 `Sources/FaceGuard.swift`。本仓库基于 FaceGuard 1.16。
